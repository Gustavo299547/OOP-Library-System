# OOP-Library-System

Library Lending System using Java OOP concepts.

## Features

- Add Books, Magazines, and DVDs
- Add Library Members
- Borrow Items
- Return Items
- List Library Catalog
- Print Library Report
- Input Validation
- Custom Library Exception

## OOP Concepts

- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Method Overriding
- Constructors
- Static Members
- Collections
- Exception Handling
